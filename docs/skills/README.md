# clip-factory skills

Everything learned while building "Not A Clip Factory" (CC BY clips for Reels, Shorts and Facebook), written as reusable playbooks. The same content drives the installed Claude skills in `~/.claude/skills/` (`cc-clip-factory`, `clip-post-scheduler`, `meta-reel-publish`).

| File | What it covers |
|---|---|
| `01-find-and-clip.md` | Finding CC BY sources, download, transcription, picking moments, 9:16 cropping, captions, encoding, checks |
| `02-post-with-github-actions.md` | The posting system: queue, Instagram sweep, native Facebook scheduling, GitHub Actions, secrets, recovery |
| `03-meta-setup-and-gotchas.md` | Meta app and System User setup, permissions, account IDs, every error we hit and its fix |
| `04-brand-art.md` | Profile picture and banners drawn with anidoodle, sizes, how to re-render |

Project files: `../CHANGELOG.md` (dated log), `../PLAN.md` (what is next), `../research/findings.md`, `../results/` (ledger and caption sheets).
Poster repo (separate): `~/Development/Projects/clip-factory-poster` (GitHub: Nevish-302/clip-factory-poster, private).

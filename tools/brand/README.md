# Brand art source

brand.ts draws the profile picture and the YouTube and Facebook banners with the anidoodle skill (flat-vector hand). It needs an anidoodle project: scaffold one, copy brand.ts into src/canvas-core/, add the avatar, ytbanner and fbcover entry files, and render with `node tools/still.mjs NAME --out out/NAME.png`. Details: docs/skills/04-brand-art.md. Finished images: ~/Downloads/cc-clips/brand/ on the user machine.
